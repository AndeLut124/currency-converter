# Currency Converter

Консольный конвертер валют на Python. Программа получает актуальные курсы валют в реальном времени через API (exchangerate-api.com).

## Возможности

- Конвертация любых мировых валют (RUB, USD, EUR, GBP и др.).
- Бесконечный цикл работы (пока пользователь не введёт 'q').
- Защита от ошибок ввода (если вместо числа ввести букву, программа не вылетит).
- Проверка на существование валюты.

## Установка и запуск

1. Клонируй репозиторий:

git clone https://github.com/AndeLut124/currency-converter.git
cd currency-converter

2. Установи зависимости:

pip install -r requirements.txt

3. Создай файл API_KEY.py и вставь свой ключ от exchangerate-api.com:

EXCHANGE_API_KEY = "твой_ключ"

4. Запусти программу:

python main.py

## Пример работы

Введите сумму (или 'q' для выхода): 1000
Введите откуда (в формате USD): RUB
Введите куда (в формате USD): USD
1000.0 RUB = 12.42 USD
